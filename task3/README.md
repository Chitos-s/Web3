# Лабораторная работа 2

Тема: модели Django, регистрация моделей в админ-панели, поиск, фильтрация и вывод данных через HTML-шаблон.

Проект: список корзин покупателей.

## Как запустить

Открыть PowerShell в папке проекта:

Установить Django, если еще не установлен:

```powershell
pip install -r requirements.txt
```

Применить миграции:

```powershell
python manage.py migrate
```

Запустить сервер:

```powershell
python manage.py runserver
```

Открыть страницу корзин:

```text
http://127.0.0.1:8000/carts/
```

Админ-панель:

```text
http://127.0.0.1:8000/admin/
```

Если нужен пользователь для админки:

```powershell
python manage.py createsuperuser
```

## Как использовать

1. Открыть `/carts/` и посмотреть список корзин.
2. Посмотреть покупателя, товары, дату создания, статус и количество товаров.
3. Открыть админку `/admin/`.
4. Посмотреть, что зарегистрированы `Customers`, `Products`, `Carts`.
5. В списке корзин посмотреть колонку с количеством товаров.
6. Посмотреть фильтры справа и поиск сверху.

## Где что лежит

- `shop/models.py` - модели `Customer`, `Product`, `Cart`.
- `shop/admin.py` - регистрация моделей в админке, поиск, фильтры, количество товаров.
- `shop/views.py` - вывод списка корзин.
- `shop/urls.py` - маршрут `/carts/`.
- `shop/migrations/0001_initial.py` - миграция и стартовые данные.
- `templates/shop/cart_list.html` - HTML-страница со списком корзин и стилями.

## Соответствие ТЗ

- Созданы три модели:
  - `Customer` - покупатель;
  - `Product` - товар;
  - `Cart` - корзина.
- Корзина содержит покупателя через `ForeignKey`.
- Корзина содержит список товаров через `ManyToManyField`.
- Все три модели зарегистрированы в админ-панели.
- В списке корзин в админке выводится количество товаров.
- Добавлены фильтры:
  - по статусу;
  - по дате создания.
- Добавлен поиск:
  - по имени покупателя;
  - по email покупателя;
  - по названию товара.
- Создана страница `/carts/`.
- На странице `/carts/` выводятся:
  - покупатель;
  - товары;
  - дата создания;
  - статус;
  - количество товаров.
- Добавлена базовая стилизация.
