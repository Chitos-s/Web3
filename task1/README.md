# Лабораторная работа: Клиент-серверное приложение для передачи файлов

Проект содержит два скрипта:
- `server.py` - сервер для хранения и передачи файлов
- `client.py` - консольный клиент

## Что реализовано
- Собственный прикладной протокол поверх TCP
- Команды: `LIST`, `UPLOAD <filename>`, `DOWNLOAD <filename>`, `EXIT`
- Передача размера файла перед содержимым
- Перезапись файла при повторной загрузке на сервер
- Обработка ошибок:
  - обрыв соединения
  - отсутствие файла
  - попытка скачать несуществующий файл
  - попытка загрузить пустой файл
  - некорректная команда
- Сервер многопоточный (поддерживает несколько клиентов одновременно)
- Сервер не завершает работу после отключения одного клиента

## Запуск
Откройте два терминала.

### 1) Запуск сервера
```bash
python server.py --host 0.0.0.0 --port 9000 --storage server_storage
```

### 2) Запуск клиента
```bash
python client.py --host 127.0.0.1 --port 9000 --dir client_storage
```

## Команды клиента
- `LIST` - список файлов на сервере
- `UPLOAD <filename>` - загрузить файл с клиента на сервер
- `DOWNLOAD <filename>` - скачать файл с сервера на клиент
- `EXIT` - закрыть соединение

## Пример
1. Положить файл `example.txt` в папку `client_storage`.
2. В клиенте выполнить:
   - `UPLOAD example.txt`
   - `LIST`
   - `DOWNLOAD example.txt`
   - `EXIT`
