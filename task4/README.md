# Лабораторная работа 3

Тема: расширение Django Admin, inline-редактирование, промежуточная модель и вычисляемые поля.

Проект: корзины покупателей с количеством товаров и итогами.

## Как запустить

Открыть PowerShell в папке проекта:

Установить Django, если еще не установлен:

```powershell
pip install -r requirements.txt
```

Применить миграции:

```powershell
python manage.py migrate
```

Запустить сервер:

```powershell
python manage.py runserver
```

Страница корзин:

```text
http://127.0.0.1:8000/carts/
```

Админ-панель:

```text
http://127.0.0.1:8000/admin/
```

Если нужен пользователь для админки:

```powershell
python manage.py createsuperuser
```

## Как использовать

1. Открыть `shop/models.py`.
2. Посмотреть модель `CartItem`: она связывает корзину, товар и количество.
3. Посмотреть, что `Cart.products` использует `through="CartItem"`.
4. Открыть админку `/admin/`.
5. Открыть любую корзину.
6. Посмотреть, что товары добавляются и удаляются внутри карточки корзины через inline.
7. Посмотреть блок `Итоги корзины` с количеством единиц товара и итоговой стоимостью.
8. Вернуться в список корзин и посмотреть эти же вычисляемые поля в колонках.
9. Посмотреть, что отмененная корзина выделяется красным статусом.
10.Посмотреть навигацию по дате сверху в списке корзин.

## Где что лежит

- `shop/models.py` - модели `Customer`, `Product`, `Cart`, `CartItem`.
- `shop/admin.py` - inline-редактирование, вычисляемые поля, подсветка статуса, фильтры, поиск, date hierarchy.
- `shop/views.py` - вывод списка корзин.
- `shop/urls.py` - маршрут `/carts/`.
- `shop/migrations/0001_initial.py` - миграция и стартовые данные.
- `templates/shop/cart_list.html` - HTML-страница со списком корзин.

## Соответствие ТЗ

- Модель корзины доработана.
- Добавлена промежуточная модель `CartItem`.
- `CartItem` хранит:
  - корзину;
  - товар;
  - количество товара.
- В админке реализовано inline-редактирование товаров внутри корзины через `CartItemInline`.
- В карточке корзины можно добавлять и удалять товары.
- Добавлены вычисляемые поля:
  - `total_quantity` - суммарное количество единиц товара;
  - `total_price` - итоговая стоимость корзины.
- Вычисляемые поля выводятся в карточке корзины в блоке `Итоги корзины`.
- Вычисляемые поля выводятся в списке корзин.
- Неактивные корзины визуально выделяются цветом статуса.
- Добавлена навигация по дате: `date_hierarchy = "created_at"`.
- Сохранены поиск и фильтрация в админке.
